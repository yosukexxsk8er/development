# ガントチャート生成 Skill

このリポジトリで定義された好みの見た目（コンパクト＋詳細）のガントチャートを、再現性高く生成するための指示書。

## 原則

1. **AIは YAML のみ書く。HTML/CSSは直接書かない。**
   見た目は `gantt/gantt_gen.py` 内の凍結CSSが保証する。デザインを変えたい場合もCSSを触らず、まず相談する。
2. **日付・期間・色は自動計算に任せる。** `left/width/top` の手計算は禁止。
3. 不明点（担当・工数・成果物）は空欄にせず合理的な仮置きを入れ、生成後にユーザに確認する。

## ワークフロー

1. ユーザの雑な指示（例: 「7/6から○○を3ヶ月で」）を受けたら、まず下記スキーマでYAML草案を作る。
2. 保存先: `gantt/examples/<案件>.yaml` またはユーザ指定パス。
3. 生成コマンドを必ず実行する（リポジトリルートから）:
   `python gantt/gantt_gen.py <入力.yaml> -o gantt/output/<案件>.html`
4. 結果報告時は「フェーズ数/タスク数/マイルストーン数」と出力パスを伝え、ブラウザでの目視確認を促す。

## YAMLスキーマ（要点）

```yaml
title: ○○開発 ガントチャート   # 必須
start: 2025-07-06              # 必須 YYYY-MM-DD
weeks: 22                      # 省略可（既定22、最大104）
milestones:                    # 省略可
  - at: 2025-08-10
    label: M1 設計完了
phases:                        # 必須 1件以上
  - name: 企画・要件定義        # 必須
    color: "#4a90d9"           # 省略可。基色のみ、濃淡は自動（省略時は既定パレット）
    tasks:                     # 必須 1件以上
      - name: 要件定義・仕様書作成  # 必須（表・ツールチップ用正式名）
        short: 要件定義         # 省略可（バー内ラベル、省略時はname）
        start: 2025-07-06      # 必須（両端含む）
        end: 2025-07-17        # 必須
        lane: auto             # auto/0/1。重なり自動回避。現行再現時のみ明示
        effort: 10人日
        owner: FE, SE
        deliverable: 要求仕様書
        # detail: 省略時はnameがツールチップに使われる
```

厳密な定義は `gantt/schema.json` を参照する。

- 期間表記 `7/6-7/17` と `title="7/6-7/17 要件定義…"` はスクリプトが自動生成（バー・ツールチップ・下表の3箇所に一貫展開）。
- 色は `color` 基色からタスク数だけ明度を上げて自動生成（タグ・凡例は基色、バー・バッジは濃淡）。
- 週ヘッダ `7/6 7/13 …` は `start + 7日*i` で自動生成。
- マイルストーン位置も日付から自動計算（`left%`）。

## よくある推測ルール

- 「3ヶ月」「12週」→ `weeks` に換算（7日=1週）。
- フェーズ名がなければ 企画→実装→検証→納品 の4分割を仮置きする。
- 工数不明 → 推定値を入れて仮置きと明示する（空欄にしない）。
- 担当不明 → `FE` / `PM` 等の妥当な仮置き＋確認。

## 禁止事項

- `gantt/gantt_gen.py` のCSS定数・HTML構造の改変（要望があればYAMLオプション追加で対応）。
- `%` 位置・色HEXの手書き指定。
- HTMLの直接編集による微調整（再現性が壊れる。必ずYAMLに戻る）。

## 検証

- リファレンス: `gantt/examples/fpga.yaml` → `gantt/output/fpga.html` が現行FPGAガントと一致すること
  （20タスク / 5マイルストーン / 表21行 / 週22）。
- 新規案件でも `python gantt/gantt_gen.py` が `OK:` で終了し、Obsidian/ブラウザで1画面に収まること。

## 別環境での使い方

このリポジトリをクローンした別のOpenCodeでは、本ファイルが `.opencode/skills/gantt/SKILL.md`
として自動発見され、`skill({ name: "gantt" })` で習得される。常用マシンでは
`~/.config/opencode/skills/gantt/SKILL.md` にコピーすれば全リポジトリから利用できる。
